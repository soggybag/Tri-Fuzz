# Tri-Fuzz (working name)

A three-band multiband distortion for guitar, after Craig Anderton's **Quadrafuzz**:
1. split the guitar into LOW / MID / HIGH bands;
2. clip each band separately;
3. mix them back with a level per band.

Clipping each band separately keeps chords far clearer than one big fuzz does, because the bands can't intermodulate with each other.

- **Starting point:** a 3-band variant (`docs/variant_schematic.gif`) whose bands all sat between 220 and 500 Hz. This version spreads them across the guitar range. Anderton's original 4-band schematic is somewhere in your files, for comparison later.
- **Schematic:** [docs/TriFuzz_schematic.pdf](docs/TriFuzz_schematic.pdf), generated by `scripts/build_trifuzz.py`. ERC 0.
- **Notes:** [docs/Design Notes.md](docs/Design%20Notes.md).

**Controls (v0.3):** one column per band, in a 125B:

```
  LOW VOL     MID VOL     HIGH VOL
  LOW DRIVE   MID DRIVE   HIGH DRIVE
  [LOW CLIP] [MID CLIP] [HIGH CLIP]      CLIP: symmetric / op-amp rails / asymmetric (even-order)
        (BYPASS footswitch)
```

Internal trims: PRE (overall gain into the bands), OUTPUT (unity with bypass), and LOW / MID / HIGH crossover frequency.
